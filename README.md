## FAQ

### What is XCutors?

XCutors is a collection of popular Roblox executors packaged with a universal loader to simplify the process of running custom Lua scripts in Roblox games.

### Is XCutors safe to use?

We provide unmodified, original executor binaries. However, always scan files with anticomponent software and use any third-party tools at your own risk.

### Why do I need to run as administrator?

Some executor components require elevated privileges to properly interface with the Roblox client and inject scripts.

### Which executor should I choose?

Each executor has different features and update cycles. We recommend trying each one to see which works best for your specific script and system configuration.

### Does XCutors support all Roblox games?

Executor compatibility can vary depending on the game's anti-enhance systems. Results may differ across different experiences.

### How do I add my own scripts to the loader?

You can paste any public script URL or local script file path into the loader's script box, then click 'Execute' to run it.

### Why isn't my executor attaching or executing?

Common solutions include: restarting Roblox and the loader, ensuring you have the latest version, temporarily disabling anticomponent, and checking if the game is compatible.

### Can I use this on macOS or Linux?

XCutors is currently designed exclusively for Windows. No official support is provided for other operating systems.
